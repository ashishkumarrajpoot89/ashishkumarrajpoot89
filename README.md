## 👋 About Me

🔭 I'm a **Data Engineer** at **Samarth eGov (Ministry of Education, GoI)**, building Python-based **ETL/ELT pipelines**, SQL workflows, and data-quality systems.
⚙️ I delivered a **rank-and-preference seat allocation engine** processing **1M+ student records** using Python, SQL, Apache Airflow, MySQL, ClickHouse, FastAPI and SQLAlchemy — cutting manual processing time by **~50%+**.
🌱 Currently upskilling in **Agentic AI & LLM apps** — RAG, MCP, LangGraph, OpenAI Agents SDK — to move into AI-focused data engineering.
📊 I love turning messy data into **reliable pipelines** and **clear insights**.
🎓 B.Tech (CSE), Bundelkhand University, Jhansi.
📫 Reach me at **beashishrj@gmail.com**
